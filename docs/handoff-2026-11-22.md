## Run it

```powershell
copy .env.example .env      # then put your own LLM_API_KEY in .env (optional, see below)
docker compose up --build -d
powershell -ExecutionPolicy Bypass -File .\scripts\reset-and-seed.ps1
```

- App http://localhost:5173, API http://localhost:8088/api. Demo login: pick a user, no password.
- Reset reloads the dataset only. The current batch of invoices exists only after **Process inbox** (Inbox page, as
  the AP Clerk). The team wanted the reset left unprocessed for testing; process it before a demo.
- Compose reads `.env` only at container start: after editing it, `docker compose up -d --force-recreate backend`.

### API key
- Optional. Without `LLM_API_KEY` extraction uses `pdftotext` + regex (`HeuristicParser`); dataset PDFs, including the
  two French ones, extract correctly that way. Images (2 PNG scans) go through Tesseract (`eng+fra`), which the backend
  Docker image installs; outside Docker you need Tesseract installed locally, or they become manual-entry drafts.
  With a key, Claude reads PDFs and images (better on unseen layouts); results are cached in `storage/llm-cache/`.
- Use your own key or get it from Matt privately. Never commit it or paste it into chat or a doc.

## Known traps

- **Invoice IDs of the current batch are not stable across resets.** `InboxService` processes emails on 4 threads,
  and each bill takes the next `AP-xxxxx` when its thread creates it. Historical IDs (AP-00001..AP-00426) never change.
  If a demo script names IDs, either make allocation deterministic (assign in `receivedAt` order before parallel
  extraction) or look IDs up after processing.
- **Gradle on Windows** may fail with "Unable to establish loopback connection". Fix for the shell:
  `$env:JAVA_TOOL_OPTIONS = "-Djdk.net.unixdomain.tmpdir=C:\some\short\path"` (create the folder first).
- November looks like a sharp spending drop on the charts because the business date is 2026-11-02.
- `docker compose up --build -d frontend` also restarts the backend (dependency), which logs the browser out; use
  `--no-deps` to rebuild only the frontend.
